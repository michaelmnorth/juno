Juno privacy policy

Last updated November 8, 2026 (access widened from read-only).

Who uses Juno

Juno is a personal app built and used by one person, Michael North. It is not available to anyone else.

What it accesses

With Michael's permission, Juno accesses his own Gmail and Google Calendar through Google's APIs (gmail.modify and calendar.events). It reads new mail and calendar changes so it can remind and brief him, organizes mail with labels, prepares draft replies, and prepares calendar events.

Juno never sends an email or a calendar invitation on its own. Each one needs Michael's explicit approval first. It does not permanently delete mail.

How data is stored

Data stays on Michael's own computer. Sign-in credentials are kept in his password manager, never in plain files. Nothing is sold, shared with third parties, or used for advertising.

Google API Services

Juno's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
